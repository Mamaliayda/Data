# دیتای همیشه روشن — AlwaysData

یک اپ اندرویدی که **اینترنت موبایل (Mobile Data) را همیشه روشن نگه می‌دارد**:

- هر **۲ ثانیه** وضعیت دیتا را چک می‌کند؛ اگر خاموش شده باشد، **خودکار دوباره روشنش می‌کند**.
- اگر خودت از تنظیمات سریع یا تنظیمات گوشی دیتا را خاموش کنی، در چند ثانیه دوباره روشن می‌شود و این اتفاق در **گزارش رویدادها** ثبت می‌شود.
- بعد از **ری‌استارت گوشی** خودش دوباره فعال می‌شود.
- با بستن برنامه (سوایپ) هم کشته نمی‌شود؛ سرویس دائمی + بررسی دوره‌ای + ویجت + کاشی تنظیمات سریع دارد.
- فقط وقتی خاموش می‌شود که **خودت از داخل همین برنامه** سوییچ «حفاظت همیشه‌روشن» را خاموش کنی.

---

## ⚠️ نکته صادقانه (مهم، بخوان)

اندروید به **هیچ** برنامه‌ای اجازه نمی‌دهد ۱۰۰٪ جلوی خاموش‌کردن دیتا را بگیرد. یعنی این کارها همیشه ممکن‌اند و هیچ اپی نمی‌تواند جلوی‌شان را بگیرد:

- حالت هواپیما (Airplane Mode)
- برداشتن سیم‌کارت
- ریست کارخانه / حذف برنامه با کامپیوتر
- در اندروید ۱۲ به بعد، سیستم جلوی «روشن‌کردن برنامه‌ای» دیتا را تا حدی گرفته است

این برنامه بهترین کاری که بدون روت ممکن است را انجام می‌دهد: **هر تلاشی برای خاموش‌کردن را در چند ثانیه خنثی می‌کند** و با معافیت باتری + سرویس دائمی، عملاً دیتا همیشه روشن می‌ماند. برای **قوی‌ترین قفل ممکن**، راهنمای «قفل کامل (Device Owner)» پایین را هم انجام بده.

---

## نصب و راه‌اندازی (۵ دقیقه)

### روش ۱ — دانلود APK آماده (بدون کامپیوتر)

1. در گیت‌هاب، تب **Actions** را باز کن و آخرین اجرای موفق **Build APK** را انتخاب کن.
2. فایل `AlwaysData-debug-apk` را دانلود و روی گوشی نصب کن.
3. اگر نصب نشد: «تنظیمات ← امنیت ← نصب از منابع ناشناخته» را برای مرورگرت فعال کن.

### روش ۲ — ساخت با Android Studio (با کامپیوتر)

1. پروژه را در **Android Studio** باز کن (Open) و صبر کن سینک شود.
2. از منوی **Build ← Build APK(s)** فایل APK ساخته می‌شود:
   `app/build/outputs/apk/debug/app-debug.apk`
3. فایل را به گوشی بفرست و نصب کن.

### روش ۳ — ساخت با گیت‌هاب اکشنز

هر پوش (push) به این ریپو به‌صورت خودکار APK می‌سازد (فایل `.github/workflows/build.yml`). کافی است در تب Actions دنبالش بگردی.

### بعد از نصب، این کارها را انجام بده (خیلی مهم!)

1. برنامه را باز کن و سوییچ **«حفاظت همیشه‌روشن»** را **روشن** کن.
2. مجوز **اعلان** و **تلفن** را بده (برای دیدن اپراتور/سیگنال).
3. دکمه **«معافیت از بهینه‌سازی باتری»** را بزن و تأیید کن — وگرنه گوشی برنامه را در پس‌زمینه می‌بندد.
4. اعلان دائمی **«دیتای همیشه روشن فعال است»** را **پاک نکن** (سوایپ نکن)؛ این اعلان یعنی سرویس زنده است.
5. (اختیاری) ویجت «دیتای همیشه روشن» را به صفحه اصلی اضافه کن و کاشی تنظیمات سریع را هم اضافه کن: نوار بالا را پایین بکش ← آیکون مداد ← کاشی «دیتای همیشه روشن» را اضافه کن.

**تست کن:** دیتا را از تنظیمات سریع خاموش کن → باید در چند ثانیه خودش روشن شود و در بخش «رویدادهای اخیر» ثبت شود. ✅

## قفل کامل (Device Owner) — قوی‌ترین حالت

با این کار برنامه **Device Owner** می‌شود: دیگر نمی‌توان آن را مثل یک اپ معمولی حذف کرد و می‌تواند مستقیماً پرچم دیتا را بنویسد.

**شرط مهم:** این دستور فقط وقتی کار می‌کند که روی گوشی **هیچ حسابی** (گوگل و…) تنظیم نشده باشد. اگر حساب داری، باید گوشی را **ریست کارخانه** کنی، بعد از راه‌اندازی اولیه و **قبل از افزودن حساب**، برنامه را نصب و دستور را اجرا کنی.

مراحل (یک بار، با کامپیوتر):

1. روی گوشی **USB Debugging** را روشن کن (تنظیمات ← درباره گوشی ← ۷ بار روی شماره ساخت بزن تا Developer Options بیاید).
2. گوشی را با USB به کامپیوتر وصل کن.
3. در ترمینال/CMD این دستور را اجرا کن:

```bash
adb shell dpm set-device-owner com.alwaysdata.app/.MyDeviceAdminReceiver
```

4. اگر پیام موفقیت آمد، تمام است. از این به بعد برنامه را نمی‌توان بدون برداشتن وضعیت Device Owner حذف کرد.

> برای برگرداندن گوشی به حالت عادی (حذف قفل کامل):
> `adb shell dpm clear-device-owner` — یا از داخل تنظیمات گوشی: تنظیمات ← امنیت ← Device Admin Apps ← دیتای همیشه روشن ← غیرفعال.

## تنظیمات باتری بر اساس برند گوشی

برخی گوشی‌ها برنامه را خیلی تهاجمی می‌بندند. این‌ها را هم انجام بده:

| برند | مسیر |
|---|---|
| **سامسونگ** | تنظیمات ← برنامه‌ها ← دیتای همیشه روشن ← باتری ← **بدون محدودیت** + «همیشه در پس‌زمینه» |
| **شیائومی / ردمی / پوکو** | تنظیمات ← برنامه‌ها ← دیتای همیشه روشن ← **شروع خودکار (Autostart)** روشن + قفل در برنامه‌های اخیر (Lock) |
| **هواوی** | تنظیمات ← برنامه‌ها ← دیتای همیشه روشن ← **اجازه اجرا در پس‌زمینه** |
| **اوپو / ریلمی / وان‌پلاس** | تنظیمات ← باتری ← دیتای همیشه روشن ← **اجازه اجرای پس‌زمینه** |
| **ال‌جی / بقیه** | تنظیمات ← برنامه‌ها ← دیتای همیشه روشن ← باتری ← **بدون محدودیت** |

## عیب‌یابی

- **دیتا روشن نمی‌شود و هشدار «سیستم جلوی روشن‌کردن را گرفته» می‌بینی؟**
  در اندروید ۱۲+ بعضی گوشی‌ها روشن‌کردن برنامه‌ای دیتا را کاملاً بسته‌اند. راه‌حل: «قفل کامل (Device Owner)» را انجام بده، یا دکمه «باز کردن پنل اینترنت» را بزن و دیتا را دستی روشن کن — برنامه از آن به بعد مراقبش می‌ماند.
- **بعد از ری‌استارت فعال نشد؟**
  مطمئن شو سوییچ داخل برنامه روشن است و مجوز «شروع خودکار» (در گوشی‌های چینی) فعال است.
- **اعلان سرویس را سوایپ کردم و برنامه خوابید؟**
  سرویس خودش دوباره بالا می‌آید (START_STICKY + بررسی دوره‌ای ۱۵ دقیقه‌ای)، ولی بهتر است اعلان را نگه داری.
- **می‌خواهم برای همیشه خاموشش کنم؟**
  سوییچ «حفاظت همیشه‌روشن» را از داخل برنامه خاموش کن. اگر Device Owner هستی، اول وضعیتش را بردار (بالا توضیح داده شده).

## ساختار پروژه

```
app/src/main/java/com/alwaysdata/app/
├── MainActivity.kt          # رابط کاربری فارسی (RTL) + مجوزها
├── AlwaysDataService.kt     # سرویس دائمی: چک هر ۲ ثانیه + روشن‌کردن خودکار
├── MobileDataController.kt  # خواندن/نوشتن وضعیت دیتا (چند روش پشتیبان)
├── BootReceiver.kt          # شروع خودکار بعد از ری‌استارت
├── CheckWorker.kt           # بررسی دوره‌ای پشتیبان (WorkManager)
├── QuickSettingsTile.kt     # کاشی تنظیمات سریع
├── StatusWidget.kt          # ویجت صفحه اصلی
├── MyDeviceAdminReceiver.kt # گیرنده Device Owner (قفل کامل)
└── Prefs.kt                 # تنظیمات + گزارش رویدادها
```
